SKYNEXUS CONNECTOR: WHAT THIS INSTALLS AND SENDS

Please read this before you continue.

WHAT IT SENDS
After you pair it with your SkyNexus account, the connector sends your own
simulator aircraft (position, altitude, speed, heading, callsign) and the
traffic the sim knows within 80 km to your own SkyNexus map, about once a
second while a flight is loaded. Pairing sends your computer's name. The
relay passes the data to your own map only and stores nothing. It also asks
GitHub for updates every 6 hours. No analytics, no telemetry.
Privacy statement: https://github.com/JoeriSmits/skynexus-connector/blob/main/PRIVACY.md

WHAT IT CHANGES ON THIS COMPUTER
- It installs into your user profile (no administrator rights).
- "Start with MSFS" (on by default): it adds one entry named
  "SkyNexus Connector" to the add-on list (exe.xml) of each Microsoft Flight
  Simulator 2020/2024 install it finds, so MSFS starts it, and it quits when
  MSFS closes. Nothing else in that file is changed, and the previous file is
  kept as exe.xml.skynexus-backup. Switch it off with "Start with MSFS" in
  the tray menu.
- It keeps its sign-in in Windows Credential Manager and writes logs to
  %LOCALAPPDATA%\nl.skynexus.connector\logs.
- Uninstalling removes the app and the exe.xml entry.

HOW TO STOP IT
Quit or Sign out from the tray icon, or uninstall it from Windows Settings.

Code signing policy: https://github.com/JoeriSmits/skynexus-connector/blob/main/CODE_SIGNING_POLICY.md
